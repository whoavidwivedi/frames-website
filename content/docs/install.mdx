## Install Frames

Download the macOS ZIP from the [official releases](https://github.com/whoavidwivedi/frames/releases/latest). Extract it and move Frames into Applications. Current releases use ad-hoc signing. macOS may ask for approval on first launch. The [project installation instructions](https://github.com/whoavidwivedi/frames#readme) cover the supported installer.

## Update an existing installation

Choose **Frames → Check for Updates**. Follow the update prompt and restart when the download is ready. The updater checks the package checksum before installing it.
